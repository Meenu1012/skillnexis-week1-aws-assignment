\## Objective



To understand cloud computing fundamentals, AWS account setup, core AWS services, IAM permissions, S3 storage, and basic cloud security management.



\## 1. Create and Configure AWS Account



\- Set up an AWS Free Tier account.

\- Explored the AWS Management Console.

\- Created an IAM user named `student-user`.

\- Assigned `AmazonS3FullAccess` permission.



\## 2. Explore Core AWS Services



\### Amazon EC2

Amazon EC2 provides virtual servers in the cloud for running applications and websites.



\### Amazon S3

Amazon S3 is an object storage service used to store files, images, documents, backups, and static website content.



\### Amazon RDS

Amazon RDS is a managed relational database service that simplifies database setup, operation, maintenance, and scaling.



\### AWS Lambda

AWS Lambda is a serverless computing service that runs code in response to events without requiring server management.
